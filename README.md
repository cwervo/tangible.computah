## Related work

Direct-manipulation tools for turning physical materials into computational
prototypes suggest a promising direction for tangible computing: capture cards,
notebooks, or paper scraps with a camera, infer constraints from their
arrangement, and deterministically generate a prototype.

- [Benjamin Wilkins' 2018 talk](https://youtu.be/z5XxgxBz3Fo?t=1103)
- [Jon Gold's 2017 talk on the technical work](https://youtu.be/iMunXpy2Ezo?si=b8Qkd0FGlBHIc_qw)
